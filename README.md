# How Ancient China Worked

An Astro static-content starter for clear, sourced answers about life, names, government, and society in imperial China.

## Run locally

```bash
pnpm install
pnpm dev
```

The configured production URL assumes GitHub Pages at `https://paulcheung-maker.github.io/how-ancient-china-worked`. Update `site` in `astro.config.mjs` if the final domain changes.
